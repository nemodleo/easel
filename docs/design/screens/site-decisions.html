  1. 1

    결과를 폰 크기 그대로 셋 나란히

    19 Nov 실제 실행이 쓴 HTML 세 장. 데스크톱(1024px 이상)에선 실제 파일을 크기만 줄인 iframe(조작 안 됨)을 스틸 위에 얹고, 폰·태블릿·JS 꺼짐은 스틸.

    스틸이 자리를 먼저 잡아 레이아웃 이동 없음. 폰 폭은 화면 높이에 맞춰 168~216px.

    81 s · 43 s · 163 s, 순서는 문장 순서(속도순 정렬 안 함). fork 표시는 run.json의 claim 결과에서.

    요청문을 그대로 위에 인용

    site/run/prompt.txt에서 잘라 씀(빌드가 원문을 확인). 전체 프롬프트는 2절 링크. 폰에선 2절 맨 위로.

    데모 명령 Copy만 accent. 나머지 Copy는 회색. Use this one은 앱 버튼 모양의 표시(누르는 것 아님, 폰에선 숨김).

  5. 5

    둘째 화면은 실제 도구 호출 타임라인

    run.json 시각 그대로 빌드 때 그림. Codex CLI는 시각 기록이 없어 순서만 아는 호출은 흐리게(범례에 그 사실을 씀). 폰은 에이전트별 작은 막대 + 각자 남긴 댓글 전문.

    설치 줄은 빌드가 main README 표에서 그대로 가져옴(--sparse 포함). Gemini 등은 README connect 절 링크.
